Final Capstone Mini-Project Challenge

Architecture Blueprint: AI-Powered College Helpdesk

Scenario: On a college portal, students ask questions regarding attendance policies, semester exam dates, department office hours, hostel curfew, and scholarship applications. The system must retrieve verified answers from official college handbooks without making up false dates or rules.

01

Prompt Engineering

Converts informal student questions (e.g., "when is last date to pay fees?") into structured queries with role constraints and tone instructions.

02

RAG (Knowledge Bank)

Searches indexed vector chunks from the College Policy Handbook, Examination Circulars, and Hostel Rules PDF.

03

LLM (Language Engine)

Synthesizes the retrieved circular excerpts into a courteous, accurate natural language response citing page numbers.

04

API Keys (Vault Secrets)

Safely authenticates requests to external LLM providers and college databases from server-side environment variables.

05

Deployment (Cloud)

Hosts the backend container and portal on secure cloud infrastructure for 24/7 student mobile accessibility.

06

Agentic AI (Workflows)

Automatically creates support tickets, routes urgent grievance emails to the warden, and requires admin confirmation before taking action.

07

Ethical Hacking

Conducts authorized security penetration tests to prevent student personal information leaks or unauthorized grading tampering.

08

Power BI / Tableau

Displays real-time analytics for the College Principal: most frequently asked questions, peak grievance hours, and resolution times.

🛡️ Critical Engineering Questions for Students:

  • Hallucination Defense: If a student asks for the examination timetable before the official circular is published, what should the RAG assistant reply? (It must respond: "The official circular has not yet been published by the examination cell," rather than hallucinating an arbitrary date.)
  • Security Boundary: Why must the API Key for the LLM never be stored directly in client-side HTML or browser JavaScript? (Anyone using 'Inspect Element' could extract the key and run unauthorized queries on your billing account.)
  • Human Review Guardrail: Why should an AI agent not change a student's hostel room assignment or update grades without warden manual confirmation? (Autonomous tools must have human-in-the-loop safeguards on destructive operations.)
